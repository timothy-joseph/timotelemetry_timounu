![UPB Drive Logo](updrive_logo.jpg "UPB Drive logo")

Formula Student Telemetry system I've developed in my first year of University
at UPB Drive

Kicad files are located in `Hardware/` and all software in `Software/` - th
firmware is located at `Software/dat\_software`, the GUI for the telemetry is
located at `Software/flask_mqtt_server`, and a helper program to load the
microsd logs in the interface is located at `Software/dat_microsd_log_to_json`
